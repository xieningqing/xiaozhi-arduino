# M2：I2S 音频链路

这是整个项目最重要的部分。慢慢来。

本篇的代码先用于理解音频链路。验证通过后，麦克风部分集成到 `Microphone.h/.cpp`，功放部分集成到 `Speaker.h/.cpp`，最终由 `firmware/xiaozhi/xiaozhi.ino` 统一驱动。工程迭代规范见 [08-整体工程与迭代规范.md](08-整体工程与迭代规范.md)。

## 先理解 I2S

I2S 是专门传音频的数字接口，比普通串口快得多，而且是"连续不断的流"。

三根核心线：

| 线 | 全称 | 作用 |
|---|---|---|
| BCLK | Bit Clock | 每个数据位一个脉冲，决定传输速度 |
| WS / LRC | Word Select | 指示当前是左声道还是右声道 |
| DIN / DOUT | Data | 实际的数据 |

关键概念：**I2S 是主从结构**。你的 ESP32 是主机（Master），它产生 BCLK 和 WS；麦克风或功放是从机，跟着时钟走。

这也解释了为什么麦克风和功放可以接在两个不同的 I2S 口上，各自独立工作。

## 关键参数

| 参数 | 麦克风 | 功放 |
|---|---|---|
| 采样率 | 16000 Hz | 24000 Hz |
| 声道 | 单声道 | 单声道 |
| 位深 | 32 位槽（数据 24 位） | 16 或 32 位 |
| 引脚 | BCLK=5, WS=4, DIN=6 | BCLK=15, LRC=16, DIN=7 |

**为什么麦克风用 32 位槽？** INMP441 输出 24 位数据，但 I2S 硬件只支持 16/24/32 位槽，所以放在 32 位槽里，高 24 位有效，读出来要右移处理。这是新手最容易卡住的地方。

## 前置：接线检查

断电，按 [硬件引脚参考.md](硬件引脚参考.md) 接好：

麦克风：
- SCK → GPIO5
- WS → GPIO4
- SD → GPIO6
- VDD → **3V3**（不是 5V）
- GND → GND
- L/R → **GND**（必须接，悬空常常完全没数据）

功放：
- BCLK → GPIO15
- LRC → GPIO16
- DIN → GPIO7
- VIN → **5V**（不是 3V3）
- GND → GND
- SD → 3V3
- 绿色端子 → 喇叭

接好后先通电，用手摸一下功放，确认不发烫再继续。

## 实验 A：读麦克风

目标：把麦克风的原始数据打印出来，说话时数值明显变大。

```cpp
#include <driver/i2s_std.h>

#define MIC_BCLK 5
#define MIC_WS   4
#define MIC_DIN  6

i2s_chan_handle_t mic = nullptr;

void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("mic test");

  i2s_chan_config_t chanCfg =
      I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_0, I2S_ROLE_MASTER);
  i2s_new_channel(&chanCfg, nullptr, &mic);

  i2s_std_config_t stdCfg = {
      .clk_cfg = I2S_STD_CLK_DEFAULT_CONFIG(16000),
      .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(
          I2S_DATA_BIT_WIDTH_32BIT, I2S_SLOT_MODE_MONO),
      .gpio_cfg = {
          .mclk = I2S_GPIO_UNUSED,
          .bclk = (gpio_num_t)MIC_BCLK,
          .ws   = (gpio_num_t)MIC_WS,
          .dout = I2S_GPIO_UNUSED,
          .din  = (gpio_num_t)MIC_DIN,
          .invert_flags = {
              .mclk_inv = false,
              .bclk_inv = false,
              .ws_inv   = false,
          },
      },
  };

  i2s_channel_init_std_mode(mic, &stdCfg);
  i2s_channel_enable(mic);
  Serial.println("mic ready");
}

void loop() {
  int32_t buf[256];
  size_t bytesRead = 0;

  // 阻塞读取，等够 256 个样本
  i2s_channel_read(mic, buf, sizeof(buf), &bytesRead, portMAX_DELAY);

  // 算最大幅度，用来观察音量
  int32_t peak = 0;
  for (size_t i = 0; i < bytesRead / sizeof(int32_t); i++) {
    int32_t v = buf[i] >> 8;      // 24 位有效数据在高端
    if (v < 0) v = -v;
    if (v > peak) peak = v;
  }

  Serial.println(peak);
}
```

### 怎么看结果

- 安静时：数值在几千以内，甚至只有几百
- 正常说话：明显跳到几万甚至更大
- **说话和不说话没区别，或者一直是 0**：绝大多数情况是麦克风的 `L/R` 没接 GND，或者 VDD 接错
- 数值永远顶到最大：BCLK 或 WS 接反了

### 采样率换算

16000 Hz 表示每秒 16000 个样本。读 256 个大约需要 16ms。

这个数字后面要用到：60ms 的 Opus 帧 = 16000 × 0.06 = **960 个样本**。

## 实验 B：播放正弦波

目标：让喇叭响出一个稳定的 440Hz 单音。

```cpp
#include <driver/i2s_std.h>

#define SPK_BCLK 15
#define SPK_LRC  16
#define SPK_DIN  7

i2s_chan_handle_t spk = nullptr;

void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("speaker test");

  i2s_chan_config_t chanCfg =
      I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_1, I2S_ROLE_MASTER);
  i2s_new_channel(&chanCfg, &spk, nullptr);

  i2s_std_config_t stdCfg = {
      .clk_cfg = I2S_STD_CLK_DEFAULT_CONFIG(24000),
      .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(
          I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_MONO),
      .gpio_cfg = {
          .mclk = I2S_GPIO_UNUSED,
          .bclk = (gpio_num_t)SPK_BCLK,
          .ws   = (gpio_num_t)SPK_LRC,
          .dout = (gpio_num_t)SPK_DIN,
          .din  = I2S_GPIO_UNUSED,
          .invert_flags = {
              .mclk_inv = false,
              .bclk_inv = false,
              .ws_inv   = false,
          },
      },
  };

  i2s_channel_init_std_mode(spk, &stdCfg);
  i2s_channel_enable(spk);
  Serial.println("speaker ready");
}

void loop() {
  static float phase = 0.0f;
  const float freq = 440.0f;
  const float sampleRate = 24000.0f;
  const int   blockSize = 240;

  int16_t block[blockSize];
  for (int i = 0; i < blockSize; i++) {
    block[i] = (int16_t)(sinf(phase) * 8000);   // 幅度不要拉满
    phase += 2.0f * PI * freq / sampleRate;
    if (phase >= 2.0f * PI) phase -= 2.0f * PI;
  }

  size_t written = 0;
  i2s_channel_write(spk, block, sizeof(block), &written, portMAX_DELAY);
}
```

### 排查

**完全没声音**：
1. 功放 `VIN` 是不是接了 5V（接 3V3 常常声音极小或没有）
2. `SD` 有没有接 3V3（拉低会静音）
3. 喇叭是不是接在绿色端子
4. `GND` 有没有和 ESP32 共地

**有杂音但不是单音**：BCLK 和 LRC 可能接反了。

**声音很小**：把 `8000` 改大一些，但别超过 30000，会削波失真。

### 为什么幅度不拉满

`sinf` 输出是 ±1.0，乘以 32767 就是满幅。但数字信号满幅容易削波产生刺耳噪声，实践中留一些余量（比如 8000-20000）更安全。

## 实验 C：视频回环

目标：麦克风采集的数据直接送到功放，戴耳机能听到自己的声音。

这个实验把 A 和 B 合起来。关键改动：

1. 用**两个任务**分别处理录音和播放（FreeRTOS）
2. 中间加一个**队列**传递数据
3. 做一次**采样率转换**（16k → 24k）

先给一个最简版本，不追求完美音质：

```cpp
#include <driver/i2s_std.h>

#define MIC_BCLK 5
#define MIC_WS   4
#define MIC_DIN  6
#define SPK_BCLK 15
#define SPK_LRC  16
#define SPK_DIN  7

i2s_chan_handle_t mic = nullptr;
i2s_chan_handle_t spk = nullptr;

void setupAudio() {
  i2s_chan_config_t rxChan =
      I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_0, I2S_ROLE_MASTER);
  i2s_new_channel(&rxChan, nullptr, &mic);

  i2s_std_config_t rxStd = {
      .clk_cfg = I2S_STD_CLK_DEFAULT_CONFIG(16000),
      .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(
          I2S_DATA_BIT_WIDTH_32BIT, I2S_SLOT_MODE_MONO),
      .gpio_cfg = {
          .mclk = I2S_GPIO_UNUSED,
          .bclk = (gpio_num_t)MIC_BCLK,
          .ws   = (gpio_num_t)MIC_WS,
          .dout = I2S_GPIO_UNUSED,
          .din  = (gpio_num_t)MIC_DIN,
          .invert_flags = {false, false, false},
      },
  };
  i2s_channel_init_std_mode(mic, &rxStd);
  i2s_channel_enable(mic);

  i2s_chan_config_t txChan =
      I2S_CHANNEL_DEFAULT_CONFIG(I2S_NUM_1, I2S_ROLE_MASTER);
  i2s_new_channel(&txChan, &spk, nullptr);

  i2s_std_config_t txStd = {
      .clk_cfg = I2S_STD_CLK_DEFAULT_CONFIG(24000),
      .slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(
          I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_MONO),
      .gpio_cfg = {
          .mclk = I2S_GPIO_UNUSED,
          .bclk = (gpio_num_t)SPK_BCLK,
          .ws   = (gpio_num_t)SPK_LRC,
          .dout = (gpio_num_t)SPK_DIN,
          .din  = I2S_GPIO_UNUSED,
          .invert_flags = {false, false, false},
      },
  };
  i2s_channel_init_std_mode(spk, &txStd);
  i2s_channel_enable(spk);
}

void loopbackTask(void* arg) {
  const int   inCount = 480;      // 16k 采样率下 30ms
  const int   outCount = 720;     // 24k 采样率下 30ms
  int32_t     in[inCount];
  int16_t     out[outCount];

  while (true) {
    size_t bytesRead = 0;
    i2s_channel_read(mic, in, sizeof(in), &bytesRead, portMAX_DELAY);
    int n = bytesRead / sizeof(int32_t);

    // 简单插值做 16k -> 24k，比例 3:2
    for (int i = 0; i < outCount; i++) {
      float src = i * 2.0f / 3.0f;
      int   i0 = (int)src;
      int   i1 = (i0 + 1 < n) ? i0 + 1 : n - 1;
      float frac = src - i0;
      float v0 = (float)(in[i0] >> 8);
      float v1 = (float)(in[i1] >> 8);
      float v = v0 + (v1 - v0) * frac;
      out[i] = (int16_t)constrain((int)v, -32768, 32767);
    }

    size_t written = 0;
    i2s_channel_write(spk, out, sizeof(out), &written, portMAX_DELAY);
  }
}

void setup() {
  Serial.begin(115200);
  delay(1000);
  setupAudio();
  xTaskCreatePinnedToCore(
      loopbackTask, "loopback", 8192, nullptr, 5, nullptr, 1);
  Serial.println("loopback running");
}

void loop() {
  vTaskDelay(pdMS_TO_TICKS(1000));
}
```

### 说明几个设计点

**为什么用 `inCount=480, outCount=720`？**
30ms 的音频：16k × 0.03 = 480，24k × 0.03 = 720。两边时间长度一样，只是采样点数量不同。

**为什么用插值而不是直接丢点？**
16k 到 24k 是 2:3 的关系，简单插值听感明显好于粗暴复制。真正讲究的做法是用重采样库，这里先用手写版本理解原理。

**为什么要 `xTaskCreatePinnedToCore`？**
把音频任务绑到核心 1，让 WiFi 等任务在核心 0，减少互相干扰。这是音频稳定性常用的手段。

**为什么把 `Serial.println` 从音频循环里移出去？**
串口打印本身很慢，放在音频循环里会拖累实时性。

### 验收

戴上耳机（或把音量调小），对着麦克风说话，能听到自己的声音。有轻微延迟是正常的。

如果只有电流声、听不到人声，检查采样率和增益；如果声音断断续续，检查是不是有别的阻塞操作。

## 常见问题速查

| 现象 | 最可能的原因 |
|---|---|
| 麦克风读数恒为 0 | L/R 没接 GND，VDD 接错 |
| 麦克风读数恒为满值 | BCLK/WS 接反 |
| 功放完全不出声 | VIN 没接 5V，SD 拉低，没接喇叭 |
| 只有嗡嗡声 | 地线没共，或 BCLK/LRC 接反 |
| 声音断续 | 音频循环里有 delay 或打印 |
| 主板发热 | 功放接到了 3V3，立刻断电 |
