# M3：联网与协议

目标：拿到服务器配置，完成 WebSocket 握手。

> 这一篇是最容易过期的部分。当前实现以 `78/xiaozhi-esp32` 的 `main/ota.cc` 和 `main/protocols/websocket_protocol.cc` 为准。先把 WiFi 和 OTA 跑通，再连接 WebSocket；不要同时调试两块。

网络模块验证通过后，把代码整理成 `src/net/` 下的 `Network.h/.cpp` 和 `Protocol.h/.cpp`，由 `xiaozhi.ino` 统一初始化，不要保留一套孤立示例。

## 协议全貌

小智服务器支持两种传输方式。我们选 WebSocket，因为简单得多。

```
① 向 OTA 端点 POST 设备信息
   ↓ 返回 websocket.url 和 token

② 连接上一步返回的 websocket.url
   请求头带 Authorization、Protocol-Version、Device-Id、Client-Id
   ↓

③ 发送 hello 文本帧
   ↓ 服务器返回 hello，含 session_id 和音频参数

④ 之后就是二进制音频帧 + JSON 控制帧来回
```

对比一下被我们绕开的 MQTT 路线：那条路要 MQTT + UDP + AES-CTR 加密 + 序列号校验，代码量是 WebSocket 的三四倍。**WebSocket 直接用 TLS 加密，音频走同一条连接，简单太多。**

### 端点不要写死

不同固件版本、不同环境和服务端迁移都可能改变 OTA 或 WebSocket 地址。官方流程是：

1. 先请求 OTA 接口
2. 解析返回的 WebSocket URL、token 和协议版本
3. 用返回的 URL 建立连接

验证阶段可以先用一个 OTA 地址做实验，但不要把 `wss://...` 地址永久写死在代码里。地址信息要从配置返回结果读取。

官方固件还会从 NVS 的 `wifi/ota_url` 读取 OTA 地址，为空时才使用编译期默认值。早期先把默认地址写在常量里即可，最终工程应把它做成可配置项。

## 需要的库

在 `工具 → 管理库` 里搜索安装：

| 库 | 用途 |
|---|---|
| ArduinoJson (v7) | 解析和生成 JSON |
| arduinoWebSockets (Links2004) | WebSocket 客户端，支持 wss |

`WiFi.h` 和 `HTTPClient.h` 是 ESP32 支持包自带的，不用装。

## M3：OTA 请求

### 这一步只做什么

只做三件事：连接 WiFi、获取设备身份、打印 OTA 返回的 WebSocket 配置。不要在这一步连接 WebSocket，也不要开始 Opus。

### 两个身份标识

| 头部 | 值 | 说明 |
|---|---|---|
| Device-Id | 板子的 WiFi MAC | 格式 `aa:bb:cc:dd:ee:ff` |
| Client-Id | 一个 UUID | 设备唯一编号 |

MAC 用 `WiFi.macAddress()` 就能拿到。UUID 只在第一次生成，存到 NVS 里，之后一直复用。**如果每次开机都换 UUID，服务器会认为是新设备。**

### 代码

```cpp
#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>
#include <Preferences.h>
#include <time.h>

#define WIFI_SSID     "你的WiFi名"
#define WIFI_PASSWORD "你的WiFi密码"
#define OTA_URL       "https://api.tenclass.net/xiaozhi/ota/"

String g_deviceId;      // MAC
String g_clientId;      // UUID
String g_wsUrl;
String g_wsToken;
int g_wsVersion = 1;

Preferences prefs;

// 生成一个简单的 UUID（v4 格式）
String makeUuid() {
  uint8_t b[16];
  for (int i = 0; i < 16; i++) b[i] = (uint8_t)esp_random();
  b[6] = (b[6] & 0x0F) | 0x40;
  b[8] = (b[8] & 0x3F) | 0x80;
  char s[40];
  snprintf(s, sizeof(s),
           "%02x%02x%02x%02x-%02x%02x-%02x%02x-%02x%02x-%02x%02x%02x%02x%02x%02x",
           b[0], b[1], b[2], b[3], b[4], b[5], b[6], b[7],
           b[8], b[9], b[10], b[11], b[12], b[13], b[14], b[15]);
  return String(s);
}

void loadIdentity() {
  prefs.begin("device", false);
  g_clientId = prefs.getString("uuid", "");
  if (g_clientId.isEmpty()) {
    g_clientId = makeUuid();
    prefs.putString("uuid", g_clientId);
    Serial.println("generated new uuid");
  }
  prefs.end();

  g_deviceId = WiFi.macAddress();
  Serial.print("device id: ");
  Serial.println(g_deviceId);
  Serial.print("client id: ");
  Serial.println(g_clientId);
}

void connectWiFi() {
  WiFi.mode(WIFI_STA);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  Serial.print("connecting wifi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println();
  Serial.print("ip: ");
  Serial.println(WiFi.localIP());

  // wss 证书校验需要正确时间，先同步 NTP，再请求 OTA。
  configTime(8 * 3600, 0, "ntp.aliyun.com");
  Serial.print("syncing time");
  time_t now = 0;
  while (now < 1700000000) {
    delay(500);
    time(&now);
    Serial.print(".");
  }
  Serial.println();
  Serial.print("time: ");
  Serial.println(ctime(&now));
}

bool fetchOtaConfig() {
  HTTPClient http;
  http.begin(OTA_URL);
  http.addHeader("Content-Type", "application/json");
  http.addHeader("Activation-Version", "1");
  http.addHeader("Device-Id", g_deviceId);
  http.addHeader("Client-Id", g_clientId);
  http.addHeader("User-Agent", "xiaozhi-learning-arduino/0.1");

  JsonDocument doc;
  doc["mac"] = g_deviceId;
  doc["uuid"] = g_clientId;
  doc["chip"] = "esp32s3";
  doc["flash_size"] = 16777216;
  doc["psram_size"] = 8388608;
  doc["firmware"] = "xiaozhi-learning-arduino/0.1";

  String body;
  serializeJson(doc, body);

  int code = http.POST(body);
  Serial.print("ota status: ");
  Serial.println(code);

  if (code != 200) {
    Serial.println(http.getString());
    http.end();
    return false;
  }

  String resp = http.getString();
  http.end();

  JsonDocument respDoc;
  DeserializationError err = deserializeJson(respDoc, resp);
  if (err) {
    Serial.print("json parse failed: ");
    Serial.println(err.c_str());
    return false;
  }

  JsonObject wsObj = respDoc["websocket"].as<JsonObject>();
  if (wsObj.isNull()) {
    Serial.println("websocket config missing");
    return false;
  }

  // 先打印完整对象，不同固件版本可能返回不同字段。
  String wsJson;
  serializeJson(wsObj, wsJson);
  Serial.print("websocket config: ");
  Serial.println(wsJson);

  // 常见字段。如果服务端字段变化，以打印出的对象为准再调整。
  g_wsUrl = wsObj["url"] | "";
  g_wsToken = wsObj["token"] | "";
  g_wsVersion = wsObj["version"] | 1;

  Serial.print("ws url: ");
  Serial.println(g_wsUrl);
  Serial.print("ws token: ");
  Serial.println(g_wsToken);
  Serial.print("ws version: ");
  Serial.println(g_wsVersion);

  return !g_wsUrl.isEmpty();
}

void setup() {
  Serial.begin(115200);
  delay(1000);
  connectWiFi();
  loadIdentity();

  if (fetchOtaConfig()) {
    Serial.println("ota ok");
  } else {
    Serial.println("ota failed");
  }
}

void loop() {
  vTaskDelay(pdMS_TO_TICKS(1000));
}
```

### 验收

串口打印出类似：

```
device id: d4:05:92:79:c2:60
client id: eebc936b-2f96-4c7b-8164-730f77cc3f70
ota status: 200
ws url: wss://api.tenclass.net/xiaozhi/v1/
ws token: test-token
ws version: 1
```

### 重要提醒

**token 是动态的，不能写死。** 服务器下发的凭据里甚至包含了你的出口 IP，换网络后必须重新请求。

**不要把 token 提交到公开仓库。** 参考项目 `winwill2012/xiaozhi-ai-arduino` 就是把豆包和 Coze 的密钥直接写进了 `data/settings.json` 并公开，这种做法不该学。

**不要把返回的 URL 当成固定值。** 验证时可以观察返回格式，代码仍然要从 OTA 结果读取 URL 和 token。

## M3：WebSocket 握手

### 先认识协议版本

官方 WebSocket 实现当前存在不同封装版本。WebSocket 握手先使用最简单的文本 JSON + 原始二进制音频载荷，不要一开始就实现带时间戳或 AEC 信息的复杂封装。

| 版本 | 音频帧形式 | 接入方式 |
|---|---|---|
| v1 | 二进制载荷直接用 Opus 数据 | 先从这个开始 |
| v2 | 带版本、类型、时间戳、载荷长度 | 需要服务端 AEC 或特殊协议时再研究 |
| v3 | 带类型和载荷长度 | 不需要时不要自己增加复杂度 |

`version` 应该从 OTA 返回值或设备配置读取，不要凭空写死。发送 hello 时带上实际使用的版本。

### 连接和头部

WebSocket 的握手发生在库内部，你只需要在连接时带上请求头。

```cpp
#include <WebSocketsClient.h>

WebSocketsClient ws;
String g_sessionId;
bool g_serverHello = false;

void onWsEvent(WStype_t type, uint8_t* payload, size_t length) {
  switch (type) {
    case WStype_CONNECTED:
      Serial.println("ws connected");
      sendHello();
      break;

    case WStype_DISCONNECTED:
      Serial.println("ws disconnected");
      break;

    case WStype_TEXT: {
      Serial.printf("text frame: %u bytes\n", length);
      String msg((char*)payload, length);
      Serial.println(msg);

      JsonDocument doc;
      if (!deserializeJson(doc, msg)) {
        const char* t = doc["type"] | "";
        if (strcmp(t, "hello") == 0) {
          g_sessionId  = doc["session_id"] | "";
          g_serverHello = true;
          Serial.print("session: ");
          Serial.println(g_sessionId);
          int sr = doc["audio_params"]["sample_rate"] | 0;
          int fd = doc["audio_params"]["frame_duration"] | 0;
          Serial.printf("server audio: %d Hz, %d ms\n", sr, fd);
        }
      }
      break;
    }

    case WStype_BIN:
      // 这里收到的是 Opus 音频数据，M4 再处理
      Serial.printf("binary frame: %u bytes\n", length);
      break;

    case WStype_ERROR:
      Serial.println("ws error");
      break;

    default:
      break;
  }
}

void sendHello() {
  JsonDocument doc;
  doc["type"] = "hello";
  doc["version"] = g_wsVersion;
  doc["transport"] = "websocket";
  doc["features"]["mcp"] = true;
  doc["audio_params"]["format"] = "opus";
  doc["audio_params"]["sample_rate"] = 16000;
  doc["audio_params"]["channels"] = 1;
  doc["audio_params"]["frame_duration"] = 60;

  String out;
  serializeJson(doc, out);
  Serial.print("send hello: ");
  Serial.println(out);
  ws.sendTXT(out);
}

bool connectWebSocket() {
  if (g_wsUrl.isEmpty()) return false;

  // 解析 wss://host/path
  String url = g_wsUrl;
  url.replace("wss://", "");
  int slash = url.indexOf('/');
  String host = url.substring(0, slash);
  String path = url.substring(slash);

  // 自定义头部
  String auth = "Bearer " + g_wsToken;
  ws.setExtraHeaders(
      ("Authorization: " + auth + "\r\n"
       "Protocol-Version: " + String(g_wsVersion) + "\r\n"
       "Device-Id: " + g_deviceId + "\r\n"
       "Client-Id: " + g_clientId + "\r\n").c_str());

  ws.beginSSL(host.c_str(), 443, path.c_str());
  ws.onEvent(onWsEvent);
  ws.setReconnectInterval(5000);
  return true;
}
```

### 在 setup 里调用

```cpp
void setup() {
  // ... WiFi 和 OTA 部分不变 ...
  connectWebSocket();
}

void loop() {
  ws.loop();          // 必须不断调用，否则收不到消息
  delay(1);
}
```

### 关于 `ws.loop()`

WebSocket 库是**事件驱动 + 需要轮询**的。`ws.loop()` 负责处理收包、心跳、重连。在 `loop()` 里必须持续调用它。

注意这里我在 `loop()` 里用了 `delay(1)`，不是因为好习惯，而是让出 CPU。后面做音频时，`ws.loop()` 要放到独立任务里，否则会被音频阻塞。

### 验收

串口应该打印出：

```
ws connected
send hello: {"type":"hello",...}
text frame: 162 bytes
{"type":"hello","transport":"websocket",
 "audio_params":{"format":"opus","sample_rate":24000,"channels":1,"frame_duration":60},
 "session_id":"..."}
session: xxxxxxxx
server audio: 24000 Hz, 60 ms
```

### 常见问题

**连接失败**：`wss` 需要正确的系统时间做证书校验。如果时间是 1970 年，TLS 会失败。用 `configTime()` 同步 NTP：

```cpp
configTime(8 * 3600, 0, "ntp.aliyun.com");
```

**连上就断**：检查头部是否完整，特别是 `Protocol-Version`。

**收不到 hello**：检查 `ws.loop()` 是否在持续调用。

**握手成功但音频不正常**：不要先改网络。先用测试音确认功放，再确认麦克风采集。只有本地音频都正常，才怀疑协议封装和 Opus。

## 协议速查表

### 客户端发送的控制消息

| 动作 | JSON |
|---|---|
| 开始听 | `{"session_id":"...","type":"listen","state":"start","mode":"auto"}` |
| 停止听 | `{"session_id":"...","type":"listen","state":"stop"}` |
| 打断 | `{"session_id":"...","type":"abort"}` |
| 唤醒 | `{"session_id":"...","type":"listen","state":"detect","text":"你好小智"}` |

### 音频帧长

服务器要 60ms 一帧，换算成采样点：

| 方向 | 采样率 | 每帧采样点 |
|---|---|---|
| 上行（录音） | 16000 | 960 |
| 下行（播放） | 24000 | 1440 |

这两个数字在 M4、M5 中都要用到。

### Arduino IDE 中的 Opus 现实情况

参考项目直接处理的是 16k PCM 和自建服务，不能证明 Arduino IDE 里已经有一组现成的、适合 ESP32-S3 的 Opus 编解码库。接入下行音频前先做一个小实验：

- 能否找到接口清晰、可在 Arduino IDE 编译的 Opus 编解码库
- 编解码时内存是否足够，是否需要 PSRAM
- 单帧编解码耗时是否满足 60ms 实时要求

如果这一实验做不通，就暂时不要接下行音频，而不是先在网络层堆代码。
