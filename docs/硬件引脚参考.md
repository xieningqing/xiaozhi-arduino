# 硬件引脚参考

本文件是全部引脚和参数的唯一来源。正式工程中的代码都以此为准。

这些数据来自现有固件的板级配置（`bread-compact-wifi-lcd`），是经过验证的可用配置。

> 先确认你手里的模块型号。如果录音模块不是 I2S 数字麦克风，或功放模块不是 I2S 数字功放，不能直接使用下面的引脚表。确认方法见 [06-参考项目与Arduino-IDE路线.md](06-参考项目与Arduino-IDE路线.md)。

## ESP32-S3-DevKitC-1 N16R8 开发板参数

开发板已确认使用 N16R8 模组：16MB Flash、8MB 八线 PSRAM。

| 项目 | 值 |
|---|---|
| 开发板 | ESP32-S3-DevKitC-1 N16R8 |
| 芯片 | ESP32-S3 |
| Flash | 16 MB |
| PSRAM | 8 MB，八线（OPI） |
| CPU | 双核 240MHz |

Arduino IDE 中必须选择 `Flash Size = 16MB`、`PSRAM = OPI PSRAM`。选错可能导致随机重启或崩溃。

USB 串口芯片也要看实物：ESP32-S3-DevKitC-1 常见的是原生 USB 和 UART 两路接口，不是所有版本都使用 CH340。具体 UART 口和驱动以开发板丝印为准。

| 屏幕引脚 | GPIO | 说明 |
|---|---|---|
| MOSI / SDA | 47 | 数据 |
| SCLK / SCL | 21 | 时钟 |
| CS | 41 | 片选 |
| DC | 40 | 数据/命令选择 |
| RST / RES | 45 | 复位 |

| VCC | 3V3 | 不要接 5V |
| GND | GND | |

## 麦克风（INMP441 类，I2S）

| 麦克风引脚 | GPIO | 说明 |
|---|---|---|
| SCK / BCLK | 5 | 位时钟 |
| WS / LRCL | 4 | 声道选择时钟 |
| SD / DIN / DOUT | 6 | 数据输出 |
| VDD | 3V3 | 接 5V 会烧 |
| GND | GND | |
| L/R | GND | 必须接，悬空常常没数据 |

采样率 16000 Hz，单声道，32 位槽（数据实际 24 位）。

## 功放（MAX98357A，I2S）

| 功放引脚 | 连接 | 说明 |
|---|---|---|
| BCLK | GPIO 15 | 位时钟 |
| LRC / LRCLK / WS | GPIO 16 | 声道时钟 |
| DIN | GPIO 7 | 数据输入 |
| VIN | 5V | 必须 5V，不能接 3V3 |
| GND | GND | 和 ESP32 共地 |
| SD | 3V3 | 常开；拉低会静音 |
| GAIN | 悬空 | 默认增益，先不接 |
| 绿色端子 | 喇叭 | 只能接喇叭，不能接电源 |

输出采样率 24000 Hz，单声道。

## 采样率总结

| 方向 | 采样率 | 说明 |
|---|---|---|
| 麦克风上行 | 16000 Hz | 发给服务器前要 Opus 编码 |
| 功放下行 | 24000 Hz | 服务器发来的是 24k Opus |
| Opus 帧长 | 60 ms | 服务器只接受这个帧长 |

上行 16k 和下行 24k 不一样，这是协议规定，不是笔误。做回环时需要在代码里做一次重采样。

## 引脚冲突检查

显示和音频使用的是两批不相邻的 GPIO，互不冲突：

- 显示：21、40、41、42、45、47
- 音频：4、5、6、7、15、16

唯一要注意的是 GPIO 48 是板载灯，别挪作他用。

## 接线安全

1. 改线前一定拔掉 Type-C。
2. 功放 VIN 接 5V，麦克风 VDD 接 3V3，别搞反。
3. 共地。所有模块的 GND 要和 ESP32 连在一起。
4. 每接一个模块，先通电看灯和温度，正常再继续。
