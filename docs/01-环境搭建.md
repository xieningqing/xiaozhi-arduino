# M0：开发环境搭建

目标：让板子跑起来，串口能看到输出。

## 1. 安装 Arduino IDE

你已经有了。打开后先做一件事：确认版本是 2.x 或更高。旧版 1.8 也能用，但库管理界面会难用一些。

## 2. 安装 ESP32 支持包

这一步是让 Arduino IDE 认识 ESP32 芯片。

1. 打开 `文件 → 首选项`
2. 找到"附加开发板管理器网址"，填入：

```
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

3. 打开 `工具 → 开发板 → 开发板管理器`
4. 搜索 `esp32`，安装 **esp32 by Espressif Systems**

优先装 3.x 版本（3.0 以上）。这个项目里用的 I2S 新驱动 `driver/i2s_std.h` 只有 3.x 才有。如果装到 2.x，音频模块会编译不过。

安装过程会下载几百 MB，耐心等。

## 3. 安装 USB 串口驱动

ESP32-S3-DevKitC-1 通常有两个 USB-C 接口：

- `USB`：ESP32-S3 原生 USB
- `UART`：板载 USB 转串口芯片

首次烧录建议插 `UART` 口。驱动类型取决于板载串口芯片，可能是 CP210x，也可能没有独立串口芯片。先看开发板背面或丝印，插上电脑后在设备管理器里确认出现的设备。

如果能正常识别并烧录，跳过这步。识别成功时可能看到类似：

```
USB-SERIAL CH340 (COM4)
```

记住这个 COM 号，后面每次都要选。

## 4. 选择开发板

`工具 → 开发板 → esp32 → ESP32S3 Dev Module`

然后逐项设置（**这些参数必须对，否则会出现各种玄学问题**）：

| 项目 | 值 |
|---|---|
| Board | ESP32S3 Dev Module |
| USB CDC On Boot | Disabled |
| CPU Frequency | 240MHz |
| Flash Mode | QIO 80MHz |
| Flash Size | 16MB (128Mb) |
| PSRAM | **OPI PSRAM** |
| Partition Scheme | 按实际 Flash 设置；16MB 可选 16M Flash (3MB APP/9.9MB FATFS) |
| Upload Speed | 921600 |
| Port | 你的 COM4 |

**关于 PSRAM 和 Flash**：开发板已确认是 N16R8。`N16` 表示 16MB Flash，`R8` 表示 8MB 八线 PSRAM，所以 Arduino IDE 中选择 `Flash Size = 16MB`、`PSRAM = OPI PSRAM`。如果第 5 个程序打印出的数值不是 16 和 8，回到这一页检查配置。

## 5. 第一个程序

正式工程已经放在 `firmware/xiaozhi/xiaozhi.ino`。在 Arduino IDE 中打开它，先确认下面的启动信息可以正常输出；不需要另外建一个临时 sketch。

```cpp
void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println();
  Serial.println("boot ok");
  Serial.print("chip: ");
  Serial.println(ESP.getChipModel());
  Serial.print("flash: ");
  Serial.println(ESP.getFlashChipSize() / 1024 / 1024);
  Serial.print("psram: ");
  Serial.println(ESP.getPsramSize() / 1024 / 1024);
}

void loop() {
  Serial.println("hello");
  delay(1000);
}
```

点击上传按钮（右箭头图标）。

**如果上传失败**：

1. 按住板上的 `BOOT` 键
2. 点一下 `RST` 键
3. 松开 `BOOT`
4. 再点上传

上传时 Type-C 要插右边那个 `UART` 口。

## 6. 看串口输出

上传完成后，点右上角的放大镜图标打开串口监视器，右下角波特率选 `115200`。

应该看到：

```
boot ok
chip: ESP32-S3
flash: 16
psram: 8
hello
hello
...
```

## 验收标准

- [ ] 串口持续打印 `hello`
- [ ] `flash` 显示 16
- [ ] `psram` 显示 8

如果 psram 显示 0，说明 PSRAM 没配好，回到第 4 步检查。

## 常见问题

**上传时报 "Failed to connect"**
按住 BOOT 再点 RST 进下载模式，或换一根数据线（有些线只能充电）。

**串口全是乱码**
波特率不对，改成 115200。

**找不到串口**
驱动没装，或 Type-C 插错口。优先插印着 `UART` 的那个；如果板子只有原生 USB，则把 `USB CDC On Boot` 改成 Enabled。

**上传成功但什么都不打印**
`USB CDC On Boot` 设成 Disabled 再试；或换到右边 UART 口。
