# 避坑清单

按现象查原因。这些坑我都实际遇到过，不是纸上谈兵。

## 上传和串口

| 现象 | 原因 | 解决 |
|---|---|---|
| 上传报 Failed to connect | 没进下载模式 | 按住 BOOT，点 RST，松开 BOOT，再上传 |
| 上传成功但无输出 | USB CDC 设置或插错口 | 插 `UART` 口并设 `USB CDC On Boot = Disabled`；只有原生 USB 时改 Enabled |
| 串口乱码 | 波特率不对 | 改成 115200 |
| 找不到 COM 口 | 驱动没装、接口不对或线不支持数据 | 按开发板丝印装驱动；换数据线；必要时换 USB/UART 口 |
| 上传很慢 | 波特率低 | Upload Speed 设 921600 |

## 板子和供电

| 现象 | 原因 | 解决 |
|---|---|---|
| 随机重启、崩溃 | Flash/PSRAM 模式选错 | N16R8 固定选 16MB + OPI PSRAM |
| 主板、芯片发热 | 5V 倒灌或模块短路 | 立刻断电，逐个模块排查 |
| 屏幕一亮就重启 | 供电不足 | 换 5V 2A 电源，别用电脑 USB |
| 功能时好时坏 | 面包板接触不良 | 重新插线，或换一行孔位 |

## 麦克风

| 现象 | 原因 | 解决 |
|---|---|---|
| 读数恒为 0 | L/R 悬空 | L/R 必须接 GND |
| 读数恒为 0 | VDD 没接或接错 | 接 3V3，不要接 5V |
| 读数恒为满值 | BCLK 和 WS 接反 | 检查 GPIO5 / GPIO4 |
| 读数正常但服务器识别不出 | 位深处理错 | 32 位槽右移 8 或 14 位取有效数据 |
| 声音很小 | 麦克风增益或距离问题 | 靠近麦克风，检查是否贴板 |

## 功放

| 现象 | 原因 | 解决 |
|---|---|---|
| 完全没声音 | VIN 接了 3V3 | 必须接 5V |
| 完全没声音 | SD 被拉低 | SD 接 3V3 |
| 完全没声音 | 喇叭没接绿色端子 | 检查接线 |
| 只有嗡嗡声 | 没共地 | 功放 GND 接 ESP32 GND |
| 声音失真 | 幅度拉满削波 | 降低幅度，别超过 30000 |
| 功放发烫 | 短路或接错 | 立刻断电检查 |

## I2S

| 现象 | 原因 | 解决 |
|---|---|---|
| 声音断续 | 循环里有 delay 或打印 | 移到独立任务，去掉阻塞 |
| 有明显噪音 | 时钟太快或线太长 | 缩短杜邦线，降低采样率试试 |
| 播放和录音互相干扰 | 共用一个 I2S 口 | 用 I2S_NUM_0 录音，I2S_NUM_1 播放 |
| 编译报找不到 i2s_std.h | ESP32 core 版本太旧 | 升级到 3.x |

## 网络和协议

| 现象 | 原因 | 解决 |
|---|---|---|
| TLS 握手失败 | 系统时间是 1970 | `configTime()` 同步 NTP |
| OTA 返回非 200 | 头部缺失或 JSON 格式错 | 检查 Device-Id / Client-Id / Content-Type |
| WebSocket 连上就断 | Protocol-Version 缺失 | 请求头必须带 |
| 收不到服务器消息 | 没持续调用 ws.loop() | loop() 里必须调用 |
| token 失效 | 换了网络 | 重新请求 OTA，token 是动态的 |
| 服务器不认音频 | 帧长不是 60ms | 上行每帧 960 采样点 |

## 代码习惯

| 问题 | 正确做法 |
|---|---|
| 全局变量满地跑 | 用类封装，一个模块一个文件 |
| 到处 delay() | 用 millis() 做非阻塞计时 |
| 构造函数里初始化硬件 | 构造函数只存参数，begin() 才碰硬件 |
| 串口打印塞在音频循环 | 移到独立任务或用队列 |
| 所有代码塞一个文件 | 按职责拆分 |

## 排查方法论

**二分法切断变量**。这是最有用的技巧。

音频不响，不要一上来就怀疑网络。顺序是：

1. 先用正弦波单独测功放 → 响不响
2. 功放正常，再单独打印麦克风数值 → 有没有数据
3. 两个都正常，才怀疑路由、缓冲、网络

每引入一个新硬件，**先单独验证它**，再和别人合并。你之前主板发热的问题，就是跳过单点验证直接合并的代价。

**记录现场**。出问题时把串口完整输出存下来，比凭记忆描述可靠得多。
