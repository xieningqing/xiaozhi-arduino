# M1：LCD ST7789 集成

目标：让 1.54 寸 LCD 显示固定文字，并把它变成后续阶段的调试窗口。

## 先确认屏幕型号

先翻到屏幕背面或看商品页，确认下面几项：

| 项目 | 你的目标值 | 为什么要确认 |
|---|---|---|
| 控制器 | ST7789 | 驱动芯片不同，初始化命令不同 |
| 分辨率 | 240 x 240 | 有些 1.54 寸屏实际是 240 x 320 |
| 接口 | SPI | 本教程按 SPI 接线 |
| 引脚 | GND、VCC、SCL、SDA、RES、DC、CS、BLK | 丝印名称可能不同，需要逐个对应 |
| 触摸 | 是否有 CST816、FT6336 等触摸芯片 | 带触摸的屏幕还有 I2C 引脚，先不要接 |

如果你的屏幕是 7 针、8 针或触摸版本，不要直接照抄接线表。先把引脚名和型号确认清楚，再更新 [硬件引脚参考.md](硬件引脚参考.md)。

## 本项目默认接线

本项目使用下面这组 GPIO：

| 屏幕引脚 | ESP32-S3 GPIO | 说明 |
|---|---:|---|
| VCC | 3V3 | 不要接 5V |
| GND | GND | 共地 |
| SCL / SCLK | 21 | SPI 时钟 |
| SDA / MOSI | 47 | 数据 |
| CS | 41 | 片选 |
| DC | 40 | 命令/数据 |
| RST | 45 | 复位 |
| BLK / BL | 42 | 背光 |

接线的原则：

- 先断电再接屏
- VCC 用 3V3
- 所有 GND 和 ESP32 共地
- 杜邦线尽量短
- 先把背光、SPI 和电源接好，触摸接口暂时不接

## Arduino IDE 需要的库

这里先使用 `TFT_eSPI`：

`工具 → 管理库`，搜索并安装：

| 库 | 用途 |
|---|---|
| TFT_eSPI (Bodmer) | ST7789 SPI 屏驱动 |

`TFT_eSPI` 不是装完就能直接用，还要配置屏幕驱动和引脚。配置方式有两种：

1. 修改库目录里的 `User_Setup.h`
2. 在 sketch 目录新建 `User_Setup_Select.h` 和自定义设置文件

本学习阶段先用第一种方式，等你能稳定点亮屏幕后，再研究更整洁的配置方式。

## 配置 TFT_eSPI

找到 Arduino IDE 的库目录，进入：

```text
libraries/TFT_eSPI/User_Setup.h
```

先备份原文件，再修改这些设置：

```cpp
#define ST7789_DRIVER

#define TFT_WIDTH  240
#define TFT_HEIGHT 240

#define TFT_MOSI 47
#define TFT_SCLK 21
#define TFT_CS   41
#define TFT_DC   40
#define TFT_RST  45

#define TFT_BL   42
#define TFT_BACKLIGHT_ON HIGH

#define SPI_FREQUENCY 27000000
```

如果屏幕方向不对，后面可以在代码里调整旋转角度。颜色反了或花屏时，先检查驱动型号、分辨率和 SPI 频率，不要先改其他引脚。

## 最小示例

先在正式工程中验证 LCD。可以临时把下面的代码放入 `firmware/xiaozhi/xiaozhi.ino`，通过后再拆成 `Display.h/.cpp` 并接回主工程。

最小验证代码：

```cpp
#include <TFT_eSPI.h>

TFT_eSPI tft = TFT_eSPI();

void setup() {
  Serial.begin(115200);
  delay(1000);

  tft.init();
  tft.setRotation(0);
  tft.fillScreen(TFT_BLACK);
  tft.setTextColor(TFT_WHITE, TFT_BLACK);
  tft.setTextSize(2);
  tft.setCursor(20, 40);
  tft.println("XiaoZhi");

  tft.setTextSize(1);
  tft.setCursor(20, 90);
  tft.println("LCD ready");

  Serial.println("lcd ready");
}

void loop() {
  delay(1000);
}
```

上传后，屏幕应该显示两行文字。

## 验收标准

- [ ] 屏幕背光能亮
- [ ] 屏幕不白屏、不花屏
- [ ] 能显示 `XiaoZhi`
- [ ] 修改文字后重新上传，屏幕内容跟着变化
- [ ] 录音、功放、屏幕的接线没有互相冲突

## 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 完全黑屏 | 背光没接、VCC 接错、BLK 没拉高 | 先查电源和 BLK |
| 白屏 | 初始化命令不对 | 确认是 ST7789，检查分辨率 |
| 花屏 | SPI 频率过高、线太长 | 降低到 10MHz 或 20MHz 试 |
| 颜色反了 | RGB/BGR 顺序或反色设置不对 | 调整驱动配置，不要改接线 |
| 文字方向不对 | 屏幕旋转方向不对 | 修改 `setRotation()` |
| 屏还能亮但文字不出现 | 坐标、颜色或字体设置不对 | 先用全屏填充测试 |

## 不要在这一步做什么

先不要上 LVGL，不要做中文界面，不要做动画，也不要把音频和屏幕一起调。先把“屏幕能稳定显示文字”和“音频驱动能独立工作”分开验证。

屏幕跑通后，下一阶段回到 [04-I2S音频入门.md](04-I2S音频入门.md)，从麦克风采集开始。接入正式工程时，把初始化放入 `Display::begin()`，把状态显示放入 `Display::showStatus()`，不要让主文件直接塞满屏幕细节。
